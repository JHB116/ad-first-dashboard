# 인수인계 — 배경과 다음 과제

## 배경

- 전체 채널 관점의 첫구매 실적 대시보드(ryunj/first-dashboard)로는 광고 세부 실적을 보기 어려워, 광고 신규 · 첫구매만 깊게 보는 대시보드를 따로 만들었다.
- 처음에는 claude.ai 대화에서 HTML(광고유형별 신규 실적 추이)과 엑셀(DA 가입 · 쿠폰 영향 진단)로 급히 분석했고, 이를 이 저장소로 옮겼다. 실제 수치 · 검증값은 공개 저장소라 여기 적지 않는다(로컬 `tests/local/expected.json`).

## 분석 맥락

- 2026-07-01 20% 앱전용 쿠폰 발행, 2026-08-01 5,000원 웰컴백 쿠폰 앱전용 변경. 트래킹은 라스트클릭 AF코드 기반이라 앱 결제로 넘어가면 광고 귀속이 끊길 수 있다.
- DA 가입은 7~8월 테스트 캠페인(Meta 신규 · 방문유저 증액, 카카오 신규고객확대 행사)이 끌어올렸고, 제외하면 하락 → 'DA 가입 분해' 화면.
- AF 기준 2026년 7월 이후 첫구매가 2024년 대비 크게 낮다. 주문고객은 비슷한데 첫구매 비중이 떨어졌다 → 'AF 첫구매 진단' 화면.
- 브랜드검색 첫구매 '지속 하락'처럼 보인 원인은 여름 브랜드(우포스 · 킨 · 아일랜드슬리퍼) 시즌 종료라는 구성 효과였다 → '브랜드 구성 효과 분해'. 2024년에도 같은 시즌 브랜드 이탈이 있었고, 차이는 나머지 브랜드가 메웠는지 여부.
- 분석 원칙은 `docs/METRICS.md` '분석 원칙'을 따른다.
